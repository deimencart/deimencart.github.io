# deimencart.github.io

Personal academic and engineering portfolio website hosted on GitHub Pages.

* **Live URL:** [https://deimencart.github.io](https://deimencart.github.io)
* **Tech Stack:** HTML5, Tailwind CSS, Lucide Icons, Google Fonts (Inter & JetBrains Mono).
* **Hosted via:** GitHub Pages (`main` branch root).

## Featured Projects Linked
* [SAC-Curriculum-Repro](https://github.com/deimencart/SAC-Curriculum-Repro) — Reinforcement learning for robotic cloth manipulation in Genesis World.
* [Voyager](https://github.com/deimencart/Voyager) — Field autonomous Ackermann UGV navigation with ROS 2 and ArduRover.
* [CLASP-Repro](https://github.com/deimencart/CLASP-Repro) — Semantic keypoint detection and grasp planning for textiles.
* [SFM-Seminar-Project](https://github.com/deimencart/SFM-Seminar-Project) — Structure from Motion and historical camera localization.
* [Topological-SUN-Repro](https://github.com/deimencart/Topological-SUN-Repro) — Active vision next-best-view exploration and topological scene mapping.
